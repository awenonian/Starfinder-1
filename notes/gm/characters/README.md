# Characters

One file per recurring character, named for the character. Copy `TEMPLATE.md`.

These files are what stop the next session replacing your characters with
better-written strangers. Facts alone won't do it — a different author with a
full dossier and no voice samples will write a competent stranger wearing the
same name.

Minor characters get files too, as soon as they turn out to recur. Texture that
carries nothing today may be load-bearing in three sessions.
