# Plans

Plan ahead. Campaign plan, session plans, scene plans if you want them.

- `CAMPAIGN.md` — the system, the starting point, and the long shape.
- `session-NN.md` — one per session.

Don't introduce clues just to have clues. Tie them to a plan you already have.

The plan can change — no plan survives contact with the players — but don't
rewrite it on a whim. Any change has to stay consistent with what has already
been revealed, and that is hard.

**Prep is stickier than conversation.** When play contradicts the plan, the
plan bends, including any scene already shaped around the old version. Go find
that scene and fix it; don't let a prepped beat carry a fact that has since
been corrected.

If a plan already exists when you resume, that plan is the thing you are
continuing. Read it before writing a new one.
